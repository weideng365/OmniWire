Functional Highlights

全方位的网络管理与安全控制

打破传统多工具割裂的运维体验，通过现代化统一控制面板全面掌控网络出入口。

WireGuard 现代化服务端

采用纯 Go 原生实现（wireguard-go），无需宿主机预装 wg 命令行工具，支持跨平台启动、密钥协商与全周期状态监控。

  • 一键生成客户端配置及二维码
  • 自动网段分配与智能冲突防护
  • 对等体动态启用、禁用与限速

OpenVPN 企业级安全接入

内置完整的 PKI CA 证书链管理与 OpenVPN 守护进程联动，支持多用户隔离、客户端状态感知与配置一键导出。

  • 一键生成 .ovpn 客户端完整配置
  • 支持全流量或内网自适应路由
  • Loopback 严格鉴权回调机制

高并发 TCP / UDP 转发

自研高效端口转发引擎，内置缓冲池复用与 Session 管理，支持单端口、多端口映射及精准出入向独立限速。

  • sync.Pool 零拷贝内存复用
  • UDP 会话映射与优雅回收
  • 实时流量统计与吞吐率换算

智能端口状态审计

基于 Worker Pool 架构的受控并发扫描器，支持对本机及内网主机的 1-65535 全端口进行毫秒级状态审计。

  • 多协程受控工作池，杜绝 OOM
  • 精准解析监听进程与占用服务
  • 一键快速探测高危暴露风险

单文件内嵌 · 零外部依赖

利用 Go 1.22+ 原生 //go:embed 特性，前端 Vue 编译产物完全嵌入后端二进制，分发无冗余文件。

  • 单个可执行二进制直接分发
  • 内置嵌入式 SQLite 数据库
  • 支持 Windows / Linux 多平台

多维运维监控大盘

直观呈现网关网络负载、活跃连接数、VPN 握手状态与设备运行指标，提供生产级系统健康度可视化。

  • 实时双向带宽图表直观展示
  • 节点在线状态即时心跳上报
  • JWT 白名单鉴权与操作审计

Deployment & Quickstart

简单、极速的部署方式

无论是通过 Docker 快速体验，还是使用编译好的二进制单文件部署，都只需数分钟。

方式一：Docker 一键部署（推荐）

利用容器化隔离环境，自动配置好底层依赖和持久化挂载。

# 1. 克隆代码仓库 git clone git@github.com:weideng365/OmniWire.git cd OmniWire # 2. 启动服务容器 (默认映射 8080 端口) docker-compose up -d # 3. 访问 Web 控制面板 浏览器访问: http://<服务器IP>:8080 默认账号: admin 密码: admin123

方式二：源码编译与原生部署

纯 Go 静态资源完全打包内嵌，直接生成单个独立执行文件。

# 1. 编译前端生产静态资源 cd web && npm install && npm run build # 2. 嵌入前端编译产物并编译后端 cd ../server go build -tags embed -o omniwire-server # 3. 运行网关服务 ./omniwire-server // 默认监听 :8110，打开浏览器即可进入管理界面
